## 설치

```sh
brew install --cask kyungryeol-yoon/tap/macinv
```

또는 아래 `MacInv-<버전>.zip`을 받아 풀고 「응용 프로그램」 폴더로 옮기세요.
처음 열 때 「확인되지 않은 개발자」 경고가 나오면 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**를 눌러 주세요(한 번만).

## 권한

권한 없이도 동작합니다(목록·업데이트·대부분의 용량). 더 정확하게 재거나 다른 앱의 보호 폴더까지 정리하려면:

- **전체 디스크 접근** — 다른 앱의 컨테이너·그룹 컨테이너 용량과 정리
- **앱 관리** — 다른 개발자의 앱을 휴지통으로 옮길 때

켠 뒤에는 MacInv를 다시 시작해야 적용됩니다. 업데이트하면 권한이 풀릴 수 있습니다 — 그때는 목록에서 MacInv를 지운 뒤 다시 추가하세요(MacInv가 알려 줍니다).
